Calculator 🧮

A simple C++ calculator that performs basic arithmetic operations on two integers.

✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Handles division by zero.

🛠️ Technologies

* C++
* iostream
* Functions
* Conditional statements
* User input

🚀 How to Use

1. Run the program.
2. Enter two integers.
3. The calculator performs the arithmetic operations.
4. The results are displayed on the screen.
